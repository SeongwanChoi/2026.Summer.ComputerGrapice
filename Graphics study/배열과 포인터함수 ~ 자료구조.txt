변수 : 프로그램에서 값이 변할수있는 데이터
상수 : 값이 변하지 않는 데이터
포인터 : 메모리 주소값을 담고있는 변수
참조자 : 메모리를 직접 가르키는 변수, 포인터와 다르게 주소값을 직접적으로 다루지 않으면서도 변수처럼 사용가능
주소값 : 실제 메모리 공간의 위치를 나타내는 값
동적 할당 : 프로그램이 실행되고있는 런타임 도중에 메모리를 할당하거나 변경하는 것
정적 할당 : 프로그램이 실행되기 전에 변수를 만들어 메모리를 할당하는 것
널 문자 : 문자열의 끝을 나타내는 특수문자

복사 : 변수를 다른변수에 대입할 경우 값의 복사가 일어난다, 이때 두 변수는 서로 다른 메모리 공간을 가지게 된다.
포인터 : 애초에 가르키고있는게 값이아닌 주소값이라 복사할때도 주소값이 복사되므로 두 포인터는 같은 메모리 공간을 가르키게 된다.
참조 : 참조자는 포인터와 다르게 주소값을 직접적으로 다루지 않으면서도 변수처럼 사용가능하다. 따라서 참조자를 복사할 경우에도 같은 메모리 공간을 가르키게 된다.

전위 연산자 : 연산자가 변수 앞에 위치하여 연산 수행을 먼저하는 연산자
후위 연산자 : 변수 뒤에 연산자가 있어 연산 수행이 다음 줄에 반영된다.

값에 의한 호출 (Call by Value) : 값을 복사하여 함수에 전달하기때문에 원본 값이 변하지 않는다는 특징이 있다.
참조에 의한 호출 (Call by Reference) : 값에 접근할 수 있는 참조자를 전달하기에 원본 값이 변할 수 있다, 메모리 구조상 원본을 참조하는것이기 때문에 별도의 메모리공간을 할당하진 않는다.
포인터에 의한 호출 (Call by Pointer) : 포인터 또한 원본값에 접근할 수 있지만 참조와 다르게 별도의 메모리 공간을 가지고 있다.

배열 : 같은 형식의 데이터를 지정된 크기만큼 연속적으로 변수로 저장하는 자료구조, 변수의 집합이다.

자료구조 : 컴퓨터에서 데이터를 효율적으로 다루기 위해 만든 방식
ㄴ알고리즘 : 자료구조 등을 통해 전체 문제를 처리하는 과정

시간 복잡도 : 알고리즘을 처리하는 대에 처리속도를 나타낸다, 적은 시간이 걸릴수록 효율적이다.
공간 복잡도 : 알고리즘을 처리하는대에 메모리 사용량을 나타낸다, 적게 사용할 수록 좋다.
점근식 표기법 : 2가지 복잡도를 이용해 도표를 만들어 효율을 비교하고 눈으로 쉽게 판단하기 위한 표기법
정렬 : 데이터에 접근하는 효율을 올리기 위해 데이터를 순서를 정해 정리해두는 작업

STL : 공식적으로 자료구조를 만들고 다룰 수 있도록 만든 라이브러리

리스트 : 데이터를 순차적으로 저장하는 구조의 선형 자료구조, 배열기반의 리스트와 포인터기반의 리스트로 나뉜다.
ㄴ연결리스트(Linked List) : 포인터를 기반으로 노드가 다음 노드의 주소로 선형의 형태를 만든 자료구조이다.
	ㄴ단일 연결리스트 : 단방향 리스트로 노드가 다음 노드의 주소값을 가자고있다.
	ㄴ환형 연결리스트 : 단일 연결리스트의 맨 마지막 노드가 맨 처음 노드의 주소값을 가지고있어 원형의 형태를 만들었다.
	ㄴ이중 연결리스트 :	환형처럼 끝과 시작노드가 이어져있을 뿐만 아니라 모든 노드가 이전 노드와 이후 노드의 주소값을 모두 들고있어 어떤 노드로 접근하든 양방향 탐색이 가능하다.
벡터 : 내부적으로 이중 연결리스트로 작동하는 자료구조, 선형 자료구조이지만 크기를 정하지 않고 만들어 크기변화에 대응하여 배열의 크기가 달라지도록 작동한다.

해시맵 / 해시테이블 : 노드에 데이터 값과 그 값의 키 값을 가지고 있어 키값을 이용하여 데이터값에 바로 접근할 수 있도록 만든 자료구조이다, 그렇기에 노드끼리 이어져 있지 않다. 
						키 값을 받으면 해당 키 값을 해쉬함수로 해쉬화 한 다음 키 체크를 하여 연결되어있는 값에 접근한다.
큐 : First In First Out 구조를 가진 선형 데이터 자료구조, 단방향으로 있을 뿐 아니라 반드시 자료구조에 먼저 넣은것 부터 나온다 즉 자료구조 내부의 데이터에 접근하거나 조작할 방법이 없다.
스택 : First In Last Out 구조를 가진 선형 데이터 자료구조, 마찬가지로 방향은 다르지만 단방향에 입력과 출력만 가능해 내부의 데이터를 조작하지 못한다.
