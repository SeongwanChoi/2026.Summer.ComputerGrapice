컬링 : 3차원 공간에서 카메라 즉 화면에 보이지않는 부분은 생성조차 시도하지않는다, 이로인해 컴퓨터의 부담을 줄인다.

월드 행렬 : 3차원 공간에서 물체를 기준점으로 두고 x, y, z의 3가지 축을 활용해 좌표단위로 이동, 회전 등을 할 수 있으며 이 값을 가지고 있는 행렬이다, 유니티에선 Transform으로 구현되어있다.
뷰 행렬 : 3차원 공간에서 화면을비추는 카메라의 시점을 조정하는 값들을 행렬로 가지고있다, 유니티등엔 Cmera가 따로 구현되어있다.
프로젝션 행렬 : 프로젝션을 위한 수학적 공식 등을 기능으로 가지고있다.
	프로젝션 : 3차원공간을 2차원평면상태로 송출할려 할 때 해당 축 방향에서 카메라 물체의 거리에 따라 가까울수록 상대적으로 더 커보이게 만든다.

로컬 스페이스 : 해당 오브젝트를 중심으로 위치를 계산함
월드 스페이스 : 공간 전체를 기준으로 위치를 계산함
뷰 스페이스 : 카메라를 기준으로 위치를 계산함
뷰 포트변환 : 카메라를 기준으로 보이지않는 부분은 만들지 않고 조명작업 후 물체를 투영하여 뷰포트로 보여줄 준비를 하는 작업



전면버퍼 : 현제 화면(프레임)의 상태를 저장하고있는 버퍼
후면버퍼 : 다음 화면의 물체들의 정보를 저장하고있는 버퍼
플리커현상 : 모니터의 주사율과 그래픽카드가 서로 맞지않는 등의 문제가 생기면 화면이 깜빡이거나 떨리는 현상이 생긴다.


지오메트리 : 3차원 공간에 랜더링되어 나타낸 물체, 물체를 표현하기위해 많은 점을 선으로 연결하여 모양을 만들었음
깊이버퍼 / Z버퍼 : 카메라를 기준으로 z축으로 존재하는 물체들의 순서를 가진 버퍼

Ambient Light : 빛을 비출때 비춘 위치 주변에 은은하게 나는 빛
Diffuse Light : 빛이 특정 물체를 투과 / 반사하여 비춰지는 빛, 색갈이 칠해진 유리전구 등

머테리얼 : 물체의 색, 질감 등의 정보를 담은 객체
텍스쳐 : 물체 위에 씌워지는 이미지
메쉬 : 폴리곤이 모여서 이루는 하나의 물체
버텍스 : 3D물체 폴리곤을 구성하는 점
버텍스 버퍼 : 점들의 데이터를 저장하는 버퍼

Billboard : 2D이미지를 3D공간에 띄운 후 항상 카메라를 바라보게 만드는 방식
