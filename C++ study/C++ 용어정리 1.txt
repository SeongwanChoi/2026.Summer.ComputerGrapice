main()함수: 컴파일 시 가장 먼저 호출되는 함수, 없어도 파일자체의 컴파일은 가능하나 결과값을 형태화해서 보거나 흐름을 만들려면 프로그램 전체의 실행순서를 정의하는 main함수가 필요하다.
문장: 단어의 조합
구문: 단어를 통해 문장을 만들기위한 규칙들, C언어 등의 소스코드 사용방법또한 포함된다.

알고리즘: 일을 처리하는 순서 일의 목적과 그 효율, 상황에 따라 다양한 처리방식이 존재한다.
데이터: 활용하기위한 정보 컴퓨터에선 변수에 담겨 각 메모리 공간에 할단된다.

함수: 프로그래밍 에서는 메서드, 1개의 작업을 분리해서 그 작업만 진행하는 파트로 만든다
매개변수: 외부의 변수값을 내부에 전달하기 위해 사용하는 변수 함수 안에서 쓰기위해 새로운 변수로 생성되고 이 메모리값은 함수가 끝날 때 사라진다.
리턴: 함수가 끝나고 전달되는것 특정 형식의 값으로 전달할 수도 있고 아무것도 전달하지않고 실행만 하는 함수로 만들수도 있다.
지역변수: 함수 내부에 선언된 변수로서, 해당 함수의 실행이 종료될 때 삭제된다.

변수: 데이터를 담기위해 메모리에 할당한 공간
데이터타입: 데이터의 형식, 숫자 문자 또는 클레스 인지에 따라 차지하는 메모리 공간도 달라진다.
기본형 변수: 프로그래밍 언어에서 자체적으로 만들어둔 데이터타입 숫자를 담는 int, float, byte 문자를담는 char 참 거짓을 판단하는 bool 등 기본적인 형식을 내장하고있다.
문자열: 문자를 표현하는 char는 문자 1개만 담을 수 있다, 문장을 담기위한 string 형식은 내부적으로 문자를 배열의 형태로 저장하여 사용하도록 만들어진 변수형식이다.
enum형: 열거형, 클래스나 구조체처럼 선언한다 차이점으로 이 형식에 들어가는 멤버는 상수 데이터만 가진다, 보통 데이터의 이름값의 집합 등으로 사용한다.

연산자: 데이터를 수학적인 계산 혹은 어떤 처리를 수행하도록하는 기능
논리연산자: 기호를 통해 참, 거짓을 판단하여 반환한다.
관계연산자: 두 개의 데이터를 비교하여 같거나 다르거나 어느쪽이 더 크거나를 비교하여 참, 거짓으로 반환해준다.

컴파일: 컴파일러는 코드를 번역하여, 컴퓨터 프로그램을 빌드하는것.
ㄴ빌드: 소스코드를 실행 가능한 파일로 만드는 과정 전체, 이 과정에 컴파일 과정또한 포함된다.
선언: 컴파일러가 알수있도록 미리 알려주는 것
함수의선언: 컴파일러가 main함수에서 사용하는 함수가 무엇인지에 대하여 알려주는 작업, C++은 위에서 아래로 읽기 때문에 main함수 위에 작성해야한다.
함수의정의: 실제 함수가 어떤일을 하는지 정의하는것, 함수의 선언과 정의는 분리할 수 있어 main함수 위에 짧게 정의만 해두고 복잡하고 긴 정의내용은 main함수 밑으로 뺄 수 있다.
함수의호출: 선언된 함수를 main함수에서 객체화 하거나 불러와 정의된 기능을 사용하는것
extern: 이 함수는 다른 파일에 있음을 알리는 키워드

조건문: 스위치는 기본변수타입만 지원하므로 문자열같은 객체타입의 변수로는 비교가 불가능하다.
그러므로 enum과 배열을 활용하여 기존에저장된 데이터에서 인덱스값을 가져와서 비교 할 수 있도록 만드는것이 코드를 이해기가 쉽다.
랜덤: 1/n 확률을 구현하기 위한 수학적인 연산을 위해 내장되어있는 Random함수를 사용했다.
확률: 보통 1/n을 구현하기위한 간단한 식을 사용하고 실제 서비스중인 게임의 확률은 더 복잡한 확률 계산법을 사용한다.
반복문: 반복적인 연산을 하는 연산식, 반복할 횟수와 조건에 따라 사용하는 연산식의 종류가 2가지 존재하며 조건문과 함께 과하게 사용하면 컴퓨터의 처리량이 비 효율적으로 올라간다.
제어문: 프로그래밍에서 데이터를 제어하는 문법 조건에 따라 나누거나 반복시키는 등의 프로그램의 실행 순서를 임의로 조정할 수 있는 문법이다.

백터(동적배열): std라이브러리에서 재공하는 자료구조로 내부적으론 연결리스트(Linked List)의 형태로 되어있다 
			각 노드끼리 순차적으로 연결되어있어 순차접근이 가능하고 내부적으로 배열 크기또한 자동으로 조절해준다.
push_Back: vector같은 자료구조의 맨 뒤에 값을 추가하는 함수, 자동으로 크기를 조절해줘 맨뒤의 노드 자리값이 몇인지 모르기에 이런 방식으로 접근한다.

객체: 클래스를 할당되어 가르키는것(포인터,참조자)
UML: 클래스 구조같은 프로그램 구조를 사람 눈으로 보기 편하게 문서화, 시각화한 방법이다.
멤버: 클래스등의 내부에 선언된 변수, 함수 등을 말한다.
접근제어자: 논리적인 오류를 피하거나 프로그래밍 편의를 위해 함수, 변수들의 접근을 일정 범위까지 제한할 수 있다.
상속: 함수로 기능을 구현하다보면 비슷한 기능들이 있을 수 있다.
	공통적이고 비슷한 기능을 한곳에 모아 부모함수로 구현하고 실제 사용될 자식함수에서 부모의 공통기능을 상속받고 일부 자체기능만 구현한다.
인스턴스: 클래스로 생성된 객체(메모리)

[객체지향]
객체: 어떤대상
추상화: 어떤 대상을 프로그램의 의도에 맞게 데이터화한것
ㄴ속성(변수): 변할수 있는 값
ㄴ동작(함수): 컴퓨터에게 컴파일 시킬 내용
클래스: 객체를 추상화해서 나타낸것
ㄴ캡슐화: 속성과 동작을 묶어서 나타내는 것.
ㄴ정보의은닉: 속성이나 동작을 숨겨서 사용할수없도록 만드는것.
ㄴ상속: 공통된 변수, 정의 등을 한곳에 모아두고 하위 단계에서 공통된 기능을 받아서 그대로 쓰도록하는 문법
ㄴ다형성: 하나의 기능을 다양한 상황에 대응해 쓸 수 있는 문법이다, 인터페이스처럼 선언만하고 상속받을 때 마다 다른 내용으로 정의하거나
												추상 클래스에서 함수를 정의하고 오버라이드로 상속받아 정의된 내용을 변경하거나 추가하여 쓸 수 있다.

생성자: 리턴값이 없고, 객체가 생성될때 자동으로 호출되는 함수.
소멸자: 리턴값이 없고, 객체가 소멸될때 자동으로 호출되는 함수.

클래스의 선언: 컴파일러에게 이런 이름의 클래스가 존재함을 알림. (h)
클래스의 정의: 컴파일러에게 클래스의 멤버들이 어떤것이 있는지 알림.(h)
클래스함수의 선언: 클래스 내부에 정의된 함수를 컴파일러에게 알림.(h)
클래스함수의 정의: 클래스 내부에 정의된 함수를 실제로 구현하여 동작하게 함.(cpp)

컴파일러가 어떤것이든 정의나 선언이 되어 있지않으면 문제가 발생한다.

클래스의 선언은 이름만 알수있으므로, 참조자나 포인터로만 사용가능하다.(함수호출 불가)
